## What is ASTER?

ASTER is an agentic analytics system that transforms natural language queries into dynamic analytical workflows.

Instead of executing a fixed pipeline, ASTER plans the required analytical steps, executes them through specialized modules, and generates explainable insights.

---

## Core Workflow

```text
User Query
      │
      ▼
   Planner
      │
      ▼
Execution Graph
      │
      ▼
Analytical Nodes
      │
      ▼
Insights & Recommendations
      │
      ▼
Explainability
```

---

## Vision

ASTER aims to bridge the gap between business users and data analytics by allowing users to ask questions in natural language while the system determines **how** to solve them.
